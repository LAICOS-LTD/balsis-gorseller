# Balsis Teknoloji — paylaşım görselleri

Instagram ve Facebook paylaşımlarında kullanılan görseller.

Instagram Graph API görseli kendisi indirdiği için görsellerin açık bir
HTTPS adresinde durması gerekiyor. Bu depo o işi görüyor.

- `genel/` — genel içerik serisi (post 1080x1350, story 1080x1920, kare 1080x1080)
- `akinsoft/gun-NN-*/` — Akınsoft sektörel kampanya, gün gün
